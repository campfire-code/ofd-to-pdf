# OFD 转 PDF

> 篝火出品 · 收录于篝火 App 应用区

国产版式文件转 PDF

![界面截图](docs/screenshot.png)

## 下载

到 [Releases](https://github.com/campfire-code/ofd-to-pdf/releases/latest) 下载对应安装包：

| 电脑 | 文件 |
|---|---|
| Windows 10 / 11 | `ofd-to-pdf_版本号_windows-x64-setup.exe` |
| Mac（Apple 芯片） | `ofd-to-pdf_版本号_mac-arm64.dmg` |
| Mac（Intel 芯片） | `ofd-to-pdf_版本号_mac-x64.dmg` |

第一次打开：
- **Windows**：如果弹出「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。
- **Mac**：如果提示「无法验证开发者」，打开「系统设置 → 隐私与安全性」，在下方点「仍要打开」。

## 怎么用

1. 把 `.ofd` 文件拖进窗口，或点「添加」「文件夹」。
2. 选好保存位置（不选则保存到下载目录下的工具文件夹），点「开始处理」。
3. 每个 OFD 生成一个同名 `.pdf`；列表里会写明页数，以及哪些内容没有转出来。

能转的：页面尺寸、文字（含位置和颜色）、线条、矩形和曲线图形、实心填充、PNG 和 JPEG 图片（如二维码）、模板页（页眉背景等）。

**做不全的部分（如实说明）**：
- **电子签章 / 印章**：不绘制，转换后的 PDF 里没有红色印章，也不能验签。需要保留签章请使用原 OFD。
- **字体**：不还原 OFD 里嵌入的字体。文字统一用 PDF 标准中文字体（宋体系）写入，由阅读 PDF 的电脑用本机字体显示，字形、字重、字距会与原件有细微差别；没有中文字体的环境里可能显示方框。
- **其他不支持**：注释、复合对象、渐变和底纹填充、裁剪区域、透明度、JBIG2 / BMP 等非 PNG、JPEG 图片、加密的 OFD。遇到时在结果里提示。
- 已用 3 份来自公开开源项目测试资源的真实 OFD（增值税发票样式、含 JPEG 图片的文件、图形测试文件）在 macOS 上人工比对过转换效果；样本有限，复杂版式（多栏公文、大量嵌入字体）未充分验证。

## 验收用例

用 `samples/` 里的三个虚构示例：

1. 拖入 `示例单页.ofd`，点「开始处理」。应显示「1 页」，生成 `示例单页.pdf`：A4 纵向，顶部灰色「示例页眉文字」（来自模板页），其下「示例电子发票」大字、一行小字、一个带分隔线的表格框、蓝色矩形、绿色圆角图形、右侧一块红色图片、最后一行「Amount: 1,234.50 CNY（示例）」。
2. 拖入 `示例多页.ofd`，应显示「3 页」，PDF 里每页都有页眉，小字行分别写「第1页」「第2页」「第3页」。
3. 拖入 `示例含签章.ofd`，应显示「1 页；注意：含电子签章，PDF 中不含印章、不能验签」。
4. 拖入任意改名为 `.ofd` 的普通文本文件，应显示失败，提示「这不是有效的 OFD 文件」。
5. 用任意 PDF 阅读器打开生成的 PDF，选中文字复制，应能复制出「示例电子发票」。

## 自己编译

需要 Node.js 22、pnpm、Rust。

```bash
pnpm install
pnpm test          # 单元测试
pnpm tauri dev     # 开发运行
pnpm tauri build   # 打包
```

界面框架在 `src/kit`（所有 campfire-code 工具共用），本工具的逻辑在 `src/tool`。
